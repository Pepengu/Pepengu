\section{Опыт}


\begin{cvblock}{Open source}
	\begin{itemize}
        \item Runner
            (\href{https://github.com/Pepengu/Runner}{Pepengu/Runner}):
            Песочница для проверки решений олимпиадных задач по программированию —
            запускает решения в Docker с ограничением ресурсов и проверкой через чекеры
        \item CodeDuels
            (\href{https://github.com/Pepengu/CodeDuels}{Pepengu/CodeDuels}):
            Платформа для проведения турниров по спортивному программированию —
            швейцарская система, дуэли один-на-один. Проверка решений
            осуществляется через \href{https://github.com/Pepengu/Runner}{Runner}
            в изолированном Docker-контейнере
        \item pepentation
            (\href{https://github.com/Pepengu/pepentation}{Pepengu/pepentation}):
            Typst-шаблон для презентаций с настраиваемой темой (светлая/тёмная),
            навигацией и 9 типами блоков (определения, предупреждения, примеры и т.д.)
        \item capybar (\href{https://github.com/CapyCore/capybar}{CapyCore/capybar}): Нативный кастомизируемый бар для композиторов на wayland работающий напрямую с протоколами wayland без посредников по типу gtk или qt
		\item MARTOS
            (\href{https://github.com/IvanArkhipov1999/Martos}{IvanArkhipov1999/Martos}):
              Martos — это элегантная операционная система реального времени, предназначенная для создания сложных мультиагентных систем. Разработчики имеют возможность писать программное обеспечение для Martos на языках Rust (предпочтительно) или C
      \end{itemize}
\end{cvblock}
